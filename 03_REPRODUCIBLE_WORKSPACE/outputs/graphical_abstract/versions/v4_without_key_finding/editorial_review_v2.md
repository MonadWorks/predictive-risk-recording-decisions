# v2 文案与布局复核

## 保留与修改

保留原版的机制约束：相同录制集合和数据在共同拟合下给出相同预测；保留主要误差和评分区间包含零、探索性扩展的 8 个独立网络 / 4 of 8 设置、未校正区间以及一项反向点估计。新增响应目标与风险近似的交叉比较、共同预算和 MAP 拟合，以及固定预测下单独检验风险预测的设计。

按两个内容块组织成四行，行内仅 common budget and MAP fit 加粗。第一块解释设计及机制，第二块说明证据边界。不宣称提出新的最优设计原理，也不将 prior averaging 直接等同于更好的风险预测。

## 比较的版本

1. 原版：机制和结果边界扎实，但缺少作者设计这一比较的目的与控制方式。
2. 方法介绍版：连续四行只讲比较设计，整句加粗；用户指出不如原版。这个版本被撤回。
3. 当前版：以原版为底，加入一行交叉比较，在机制句后连接固定预测的风险检验；仅加粗短语。保留关键结果与探索性限定。
