# Roadmap：从问题与方法依据，到可解释的非线性响应实验

> 阶段更新：下述为执行前的路线记录。2×2已实现，并完成开发、40J主评价、另40J风险预测及8J的100节点扩展。主要区间仍跨零；最新结果和后续判断见《阶段二研究报告》与《研究包导读》，实际合同以v2协议为准。

2026-10-16。根据最新要求修订：目标是**范围受控、论证完整、方法有研究深度**。最小先导用于排查可行性；正式论文不以尽量小或尽量少的方法为目的。允许优雅、较前沿的处理，只要它解决一个明确瓶颈，并能在Mac预算内公平评价。

## 1. 研究主线与原则

总问题仍是：有限神经记录能否支持指定刺激响应预测？进一步把值得深入的部分定位为：

> **在接口位置受限和生理参数不确定时，活动/响应重建与目标导向设计所采用的局部风险，何时能代表实际非线性预测误差？若不能，能否用低成本、考虑参数不确定性的设计改善这种失配？**

这不是宣称已经发现局部方法失效。现有先导仅发现端点依赖、指标权重差异和样本影响，尚不足判断原因。下一阶段必须区分“任务目标不同”“局部近似不同”“信息来源不同”和“实现问题”。

六项原则：

1. **一个科学问题贯穿全篇。**网络、统计与AI方法分别承担模型、信息评估和预测的职责；每一张图回答同一问题的一层。
2. **先进方法必须处理已定义的困难。**允许集合近似、非线性不确定性传播等处理，但先明确它相对单点近似多解决了什么。不预设要用RL、GNN或LLM。
3. **信息预算公平，计算代价透明。**每方法相同可用结构、先验、测量通道和样本；方法若使用更多计算，报告成本，不把更大信息量伪装成更好算法。
4. **已有方法与拟议贡献分开。**目标导向设计、参数集合、局部协方差都已有前史。候选贡献是神经任务中的机制/边界或经过验证的低成本处理，不保证一定成立。
5. **现象、解释和外推逐层验证。**一种条件下误差较小不是机制证明；真实结构不是实测活动；生成模型结果不是生物有效性。
6. **按闸门推进，允许否证。**不因结果不漂亮反复加样本、换指标或改目标；保留不利样本。若最后只得到经典专门化收益，就保留为研究笔记，不硬撑新方法文章。

## 2. 论证闭环是什么

**生物接口的指定功能需求 → 固定模型和响应q → 有限信息下配置记录 → 相同测量预算拟合 → 留出刺激响应评价 → 诊断风险代理的有效/失效条件 → 用独立条件验证解释及必要的改进。**

闭环不要求加入真实机器人、额外组学和在线控制。它要求问题、设计准则、实验真值、评价和结论在同一个任务上对应。可以有方法深度，也必须说明其适用域。

## 4. 怎么把方法做出来

### 4.1 先有共同的数学合同

使用已审计的softplus率网络作开发基座：固定有符号J，未知θ=(log gain,bias)，已知初值；观测为rate r。主目标q是固定刺激相对无刺激的一个读出积分差分；另设全节点积分差分向量Q。

观测灵敏度F、目标灵敏度a=∇q和G=∂Q/∂θ，以及相同先验/噪声给出：

\[
C_M(\theta)=\left[\Lambda+F_M(\theta)^TR^{-1}F_M(\theta)\right]^{-1}.
\]

这些是已有局部实验设计工具。先在纸上写明输入输出、尺寸、单位、假设和目标，再实现，避免把数值结果反推成方法定义。

### 4.2 一个有研究深度、又可控的候选：2×2设计

用两个因素拆解结果，而不是堆很多算法：

|  | 单一名义参数 | 有限参数集合 |
|---|---|---|
| 全响应向量目标 | tr(G C_M Gᵀ)/N | 在相同参数集合上平均向量局部风险 |
| 指定标量目标 | aᵀC_Ma | 在相同参数集合上平均标量局部风险 |

这样可以分别问：**收益来自任务专门化，还是来自更充分考虑参数不确定性？两者是否交互？** 集合版向量基线同样升级，避免只有我们的方法得到更好的不确定性处理。

候选集合准则可明确写成

\[
\bar R_q(M)=\frac1L\sum_{\ell=1}^{L}
a(\theta^{(\ell)})^T C_M(\theta^{(\ell)})a(\theta^{(\ell)}),
\]

向量版在同样θ集合上用trace风险。先固定L=8或16。设计集合从所有方法共同知道的先验生成，不能围绕真值采样。**这是已有局部设计的集合平均候选，不是精确Bayesian预测风险，也不是完整非线性EIG的新实现。**它仍可能漏掉设计后后验形状，须通过实际响应误差验证。

当前无需共同先导数据D0。若以后改用D0得到参数集合，必须先冻结其测量成本、节点池和用途，并让所有方法使用同样D0；不能在有限记录问题里偷偷使用全节点预训练。

为隔离“选点”效应，四种方法选择后使用同一个MAP拟合和同一种非线性q预测。暂不同时改变选点、拟合器和输出集成。集合计算增加的时间单独记录。

### 4.3 怎样把“优雅方法”变成证据

首先在少量固定案例中，将局部预测方差与参数扰动下的非线性q变化对照，检查梯度方向、曲率和工作点偏离。集合平均若只改变内部风险，没有降低实际误差，就不能算解决问题。

若这一步揭示明显非Gaussian或长退化方向，才增加**少量案例**的后验推送/预测profile诊断，并按其统计含义报告。后验推送、profile、EIG不是同一种方法：不能把prior惩罚的MAP目标直接当频率学profile置信度，也不能把EIG称为更精确的平方误差。

方法主张的候选结构是：发现并解释一种局部风险失配 → 证明其与神经工作点/接口约束的关系 → 用一个低成本处理在独立条件上改善。若链条中间不成立，允许收缩成适用边界研究。

## 5. 实验怎么展开

### 开发与最终评价分离

当前种子100–111已经用于探索，不能再作为未经查看的最终测试。下一轮预登记新的网络/参数/目标种子；方法选择完成后，再生成封存验证集。若看了验证结果后改方法，该集合转为开发数据，不能继续宣称独立最终测试。

### 首轮正式协议的建议规模

- 开发系统N=12，随后单例计时决定一个N约100的已发表模型基准；不同时上脉冲网络、大连接组和身体动力学。
- 同一刺激下3个预定读出，避免现在alternate task同时改刺激与读出的混淆。
- 每结构5次测量噪声，按结构汇总；同一图不同参数、同一参数不同噪声分别标记。
- M=3/6、端点允许/排除；所有方法统一可行域。跨目标比较时使用共同候选池，避免某任务偷偷可测端点。
- 主比较为上面的四种设计；保留随机与匹配刺激活动参照。原Fig.8算法先在其适用模型内校准，映射到新模型时注明适配。
- 同一原始噪声场提供不同集合的测量；相同拟合器、初始化、停止规则和先验。报告失败实例和设计/拟合时间。

### 评价必须回答三层问题

1. **实际表现：**原始q RMSE、配对绝对误差、全响应向量误差；归一风险作预定辅助，不挑有利排名。保留样本影响诊断。
2. **机制与校准：**局部风险是否预示真实误差，端点限制、gain/bias与工作点如何改变它；不能只画相关散点就叫机制证明。
3. **改进与代价：**集合处理是否改善独立响应误差，是否牺牲其他目标，增加多少计算；与集合向量基线公平比较。

先冻结主要比较与统计单位，探索阶段决定合理效应/误差尺度，再封存验证。重复噪声不能冒充独立网络；多条件探索不提供确认性显著性。

## 6. 数据、环境与算力安排

已有本地专用venv入口、直接依赖版本和可重跑先导，不需要先搭一个重型平台。核心程序只需NumPy/SciPy，Matplotlib用于图；目前没有GPU、云算力或大模型需求。

数据顺序为：独立合成数据 → 一个来源明确的已发表生成模型基准 → 若字段和许可适格，再用一个经验连接结构。第三层增加结构外推，仍不等于生物活动验证。Sourmpis真实记录池缺少本题所需的联合记录—刺激，暂不硬接。

本机N=12的336拟合耗时8.02秒，说明小网实验余量充足。集合设计和N约100需要各自测量，不能直接按这8秒承诺。每新增模型先做≤30分钟试跑；阶段正式计算暂设≤4小时上限，整体机器预算不超过1–2天。方法深度来自问题与诊断，不靠把算量顶满。
