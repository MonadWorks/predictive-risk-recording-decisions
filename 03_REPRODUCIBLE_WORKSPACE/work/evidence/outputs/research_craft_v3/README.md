## 这轮调研改变了什么判断

### 1. 成熟论文的“线”首先是问题和证据的承接

Kim2023到Min2025的同组生物机器人工作，展示了如何从直接肌肉驱动推进到神经—肌肉接口：新模块对应新问题，已证明的调制没有被写成尚未实现的精确控制。我们应借鉴这一推进方式，不能借它们的实体输出替自己的模拟补上证据层。

本研究有三条直接谱系：**已知连接下的不完全生理辨识 → 目标量导向实验设计 → 用途相关的刺激响应验证**。Beiran提供直接模型和选点近邻，Attia等提供方法原理，Sourmpis/Lappalainen帮助区分拟合与验证。每条引文有预定职责，不能把领域名人堆在背景段末。

### 2. 好的阴性结果写作不是反复宣布自己谨慎

JAMA诊断研究先回答医师使用工具的主要问题，再解释独立模型表现；NEJM药物案例区分中间指标与主要获益。对我们，风险预报或某个探索格变好，不能替代冻结的实际误差比较。另一方面，区间跨零也不能写成方法等价或已经证明无效。

新版用“场景＋比较＋效应/区间＋含义”组织结果，把执行日志和重复的自我辩护移出科学叙事。研究仍未证明稳定集合优势；这一事实没有因润色而改变。

### 3. “图丑”的根源包含物理尺寸、信息结构和统计语义

旧raw-risk图约404 mm宽，缩到180 mm后9 pt约为4 pt。新版按项目暂定180 mm版面设计（图形摘要暂定190 mm；均不是会议或期刊认证尺寸），主图保留配对关系、效应和区间；全条件拆成补充图。使用两因素编码、相同轴限、直接标签和简短图内文字。PNG的DPI不能弥补缩版后字体过小。

当前Fig.1采用[固定首个J5000的实际模拟观测](figure_redesign/data_overview/fig1_data_overview.pdf)，不按效果挑选单例。Fig.2a/b把nominal MSE与描述性log₂(E/N)并列呈现，c单独保留raw mean-MSE difference及97.5%区间。Fig.3a比较同一预测的风险与实际MSE，b显示全部40个score差，c用独立尺度显示mean及95%区间。完整差值分布和次要条件继续在补图中保留。描述性比值不替换主要估计量，群体区间不与个体尾部共轴。

### 4. 技巧有适用条件，好的范例也需要核查

CS演讲中“Related Work放后面”“Introduction只一页”不强制迁移到生物医学文章；Nature Medicine的病例箱图也不能让我们把内部噪声重复当独立网络。第三方绘图style改善默认值，不能替我们选择统计单位或评价量。

本次还修正一项旧笔记覆盖不足：Lappalainen2024正式论文应按本轮核读的主文Fig.1–5理解，早期笔记仅列到Fig.4不够完整。旧文件保留为历史记录，新案例笔记明确访问范围。漂亮来源也不免除对图号、估计量和数值的核对。

## 可复用的沉淀结构

| 资料层 | 保存什么 | 何时复用 | 不承担什么 |
|---|---|---|---|
| 来源卡 | URL/版本/访问深度、读到的具体位置 | 判断能不能引用、是否还需全文 | 不因“下载过PDF”就声称通读 |
| 同族案例 | 问题→方法→证据→边界及图序 | 定义自己的研究增量和证据链 | 不是可替换名词的仿写模板 |
| 原则与条件 | 一个有出处的选择及适用/失效条件 | 写作和图形决策 | 不把个人风格普遍化为硬规范 |
| 引用职责与段落图 | 每段的问题、推断、来源和承接 | 写前规划、写后逆向检查 | 不用过渡词制造不存在的逻辑 |
| 图形合同 | 面板问题、独立单位、数据列、变换、区间 | 统计图设计和复跑 | 不在绘图时暗改统计 |
| 代码与验收 | 可运行style/renderer、尺寸、字体、hash、视觉复核 | 低成本可靠复用 | 不认证科学价值或保证接收 |

这些层可以带到医学、药学、计算机与机器人研究。每个项目仍需重新定义测量机制、独立样本、因果识别、数据许可和真正的科学问题。

## 关于资料来源和审读限制

论文、作者博客、期刊/统计建议、GitHub代码与技能、中文经验都可以提供线索，但用途不同。没有按期刊分区/影响因子列质量排行榜，也没有推断作者母语。具体案例的文本和图注阅读、图像视觉阅读分别记录。

知乎官方CLI已安装但未配置授权，本轮没有读取个人资料或配置账号。公开搜索找到中文写作过渡与色盲配色条目，但直接原文访问失败，故只保留为搜索线索，没有称作精读或作为规范依据。搜索中关于“AI工具自动符合规范、抽看几个点即可靠”等营销性主张未采纳；核查全部图源和估计量比相信这类承诺可靠。

外部论文和博客没有整篇复制进包，图也未挪作我们的成果。文章只引用提供科学支撑的来源；写作/图形建议留在本资料库。第三方GitHub技能只做内容和依赖审计，没有安装或执行其脚本。science-plot-formatter借鉴的是“最终物理尺寸→前后核验→有界样式修正”的工作流；未运行所谓第三方formatter CLI。先完成编码设计，再由本地代码处理glyph、mathtext、minor ticks、线条与尺寸。其固定版本审计时为8 stars，许可未明，不以热度或工具名担保科学质量。

早期AI概念图候选已弃用并移至工作区 `work/editorial_v3/rejected_imagegen/`，不进入交付图，也没有继续生成图片的待办。交付Fig.1和图形摘要均以当前确定性代码、真实模拟源表与图注为准；旧概念图保留在工作区 `figure_redesign/baseline/`，不收入交付压缩包；正文当前Fig.1为 `figures/fig1_data_overview.*`，其重建记录和数组在 `figure_redesign/data_overview/`。

## 复用方式

先读Skill的`SKILL.md`，按任务选择references；无需把所有案例塞进每次模型上下文。通用样式只控制显示，不计算统计。具体项目的renderer与源表保存在包级`scripts/`和`source_data/`，不冒充适用于任何数据的一键科研工具。

当前环境可使用原工作区的`work/research-v2-env/bin/python`。从本包根目录运行：

```sh
MPLCONFIGDIR="$PWD/.cache/mpl" XDG_CACHE_HOME="$PWD/.cache/xdg" /absolute/path/to/python scripts/render_figures.py
```

Matplotlib/NumPy版本与v2相同，依赖说明沿用其锁文件。该renderer生成8幅统计图，并核对、复制已审计的真实数据Fig.1，共9幅。Fig.1从冻结模拟器重建的入口是 `figure_redesign/data_overview/make_data_overview.py`，这一步需要原始v2伴随包；本v3包已保留其数组、CSV和全部矢量导出。图形摘要入口 `submission/graphical_abstract/make_graphical_abstract.py` 直接读取本包源表，可独立重绘。输出PDF和SVG便于编辑、PNG便于预览；图注和来源数据作为同一交付单元。重新渲染可以改变文件字节或平台字体，不能改变记录的科学估计量。
