# 图表重做的目标、凭证与比较方法（v6）

2026-10-18。先定标准，再改图。本文件在调研代理返回前写成；调研结果出来后只补具体数值，不改框架。

## 1. 目标（一句话）

**每幅图在版式、字体、线宽、配色、标注上和同类开放获取期刊（Nature 系、eLife、PLOS）的计算神经科学图没有“信息图感”的差别；缩到 180 mm 宽时仍可读；每个数字可追到源表；同时有一套固定的、可辨认的个人风格（白底，粉色系主导，一致的角色配色与图标）。**

“个人风格”只能落在不破坏规范的地方：配色、一套统一的小图标、标注线的画法、面板标题的字重。版式、字体族、坐标轴样式保持期刊常规。

## 2. 需要看到什么凭证（三层，缺一层不算“更好”）

### A. 自动检查（客观，可重复，脚本化为 `figure_qa.py`）

| 检查项 | 通过线 | 为什么 |
|---|---|---|
| 字体全部嵌入、单一字体族 | `pdffonts` 全部 emb=yes；数据图只出现 1 个无衬线族 | 期刊印刷与一致性 |
| 最小文字（按最终 180 mm 宽度） | ≥ 6 pt，最大 ≤ 9 pt（分图标签除外） | Nature 规格 5–7 pt 的保守取值 |
| 文字框互不重叠、不出画布 | 0 处 | 最常见的“不规范”来源 |
| 文字对比度（对白底） | ≥ 4.5 : 1 | 可读性 |
| 三个语义色两两色差（含 3 种色觉缺陷模拟） | CIE76 ≥ 25 | 色觉缺陷读者 |
| 灰度下三个语义色明度差 | L* 间隔 ≥ 12 | 黑白打印 |
| 线宽 | 数据线 0.75–1.5 pt；坐标轴 0.5–0.75 pt；无粗于 2 pt 的线 | 避免海报感 |
| 禁用元素清单 | 0 个：圆角卡片、彩色圆形编号、渐变、阴影、图内整段说明文字、“Key insight/What this shows”之类框、页脚版权/声明条、占满半幅的巨型数字 | 这些是信息图手法，不是论文图 |
| 数字追溯 | 每个显示的数值在脚本里有断言，指向 `source_data/` | 诚实、可复核 |
| 面板标签 | 小写粗体 a, b, c；位置一致；每幅多面板图都有 | 期刊惯例 |
| 光栅文字 | 0（文字必须是矢量/可选中） | 排印质量 |

### B. 对照证据（回答“是不是真的比原来好看、更学术”）

1. **同尺寸并排**：旧版（v4/v5）与新版按 180 mm 实际宽度导出，并排放进同一张对比页；再各缩到 60% 看一遍（模拟期刊 PDF 里的实际观感）。
2. **盲评打分**：至少 3 个独立评审代理，看**随机排序且不标注新旧**的图，按下表量表打分；评审代理不知道哪张是新版，也不读我们的设计说明。
3. **参照集对比**：把新图和 3–5 幅同类开放获取期刊图（来自 CC-BY 论文，只在内部比较，不进入我们的产出）放在一起，让评审回答“哪几张最像期刊论文里的图”，并说明理由。新图不应是最像信息图的一张。
4. **色觉与灰度版**：同一张图的正常、红色盲/绿色盲/蓝黄色盲、灰度 5 个版本并排，要求主要结论仍可读。

**盲评量表**（每项 1–5 分）：①像期刊图而非信息图；②文字清晰度与层级；③配色舒适度与区分度；④版面平衡与留白；⑤标注是否帮助而非抢戏；⑥数据墨水比（有没有多余装饰）；⑦风格辨识度；⑧专业感；⑨5 秒可读性（盲看者能否一句话说出结论）；⑩跨图一致性（整套图是否像同一套设计）；⑪让人记住的程度（审稿人会不会主动称赞这幅图）。

基线问题与“好”的定义见 `FIGURE_AUDIT_BASELINE.md`。

**“确实更好”的判定**：新版在盲评中**每一项均不低于旧版**，总均分**至少高 1 分**，且 A 层检查全部通过。任何一项下降，回退该项设计，不用其他项的提升抵消。

## 3. 怎么系统性地优化（循环，不是一次性重画）

1. **基线**：把现有 v4/v5 的全部图过一遍 A 层检查和盲评，记下基线分和具体扣分点。
2. **设计变量**（一次只动一类）：配色 → 字体与字重 → 版式与留白 → 标注方式 → 图标与示意图 → 技术栈。每类改完立刻重跑 A 层 + 盲评。
3. **保留规则**：只保留使总分提高、且没有任何单项下降的改动；记录在 `figure_changelog.md`（改了什么、为什么、分数前后）。
4. **停止条件**：达到判定线，或连续两轮没有提升。
5. **个人风格的落点**：固定一套粉色系主导的角色配色（A/B/C、中性灰、热图双向色）；一套统一线条粗细的专业小图标（神经元、电极阵列、网络、肌肉/机械臂，自绘矢量，不用有授权限制的素材，或使用明确 CC 许可并署名的库）；一种标注线画法（细线、短箭头）；面板标题统一字重。除此之外一律遵守期刊常规。
6. **不动的东西**：所有统计量、区间、计数、轴的含义与数据点。每次出图脚本里的断言保证这一点。

## 4. 立即要去掉的“非规范”元素（示例清单，随评审补充）

- 示意图里的 “Key insight” 侧栏、图形摘要里的深色 “WHAT THIS SHOWS” 条：这些文字属于图注或正文，不属于图。
- 图形摘要与图内的 “Simulation only; no biological validation” 页脚条：移入图注。
- 彩色圆形编号徽标、圆角浅底卡片、68%/65%/19 这类放大的统计数字：改为期刊式面板标题（小写粗体字母 + 一行常规字重标题）与坐标轴上的数值标注。
- 衬线大标题：数据图不用；图形摘要如保留标题，用同一无衬线族。

## 5. 技术栈决定的依据

由调研代理对比 matplotlib、R/ggplot2（ragg）、TikZ/pgfplots 后给出推荐；本机已有 matplotlib 3.10、R 4.3.3（ggplot2、ragg、cowplot、scales、ggrepel）、TeX Live 2023（TikZ、pgfplots）。决定原则：数据图选**生成的 PDF 字体最规范、期刊最常见、你们最容易复跑**的一套；示意图选**矢量编辑友好**的一套。结论写入 `figure_craft_research_v6.md`，不凭感觉换栈。
