# 调研升级指南：怎么写论文、怎么画图、怎么让结论有分量又不失真

2026-10-17。这是对 v3 调研（`prior_case_studies/`、`writing_figure_skill/`、`conference_research/`）的整合与升级：先给一张"该读什么"的地图，再把分散的结论压成可直接照做的清单，最后单独回答"怎样让结论更有冲击力"。本文不新增实验，不改变任何冻结数字。

## 2. 写论文：压缩成八条可执行的规则

1. **先写一句话主张，再写摘要。** v4 的主张是"先验平均风险经常不改变记录决策；主要比较的误差和预报改善没有被建立；探索性扩展提示了值得确认的条件"。三层各有证据，各自标注强度。
2. **Introduction 每段回答一个读者此刻会问的问题**：为什么记录配置要和任务挂钩 → 连接结构为何不够 → 验证对象是什么 → 现成准则解决了什么、留下什么 → 本文怎么分离这两种收益。
3. **结果小节的标题就是该节的发现**，不是主题词。v4 的 2.2 标题直接写出"经常选同一组记录，主要误差比较未建立改善"。
4. **主比较先冻结，次要结果标明身份。** 次要和探索结果可以有利，也可以写进摘要，但必须带着"探索性、n=8、未做多重性校正"这类限定一起出现。
5. **把区间当边界读，不当判决读。** 跨零不是"无效"，也不是"等效"。可以写区间排除了什么：v4 指出三响应比较的 97.5% 区间排除了超过约 3% 的均值 MSE 下降，而单响应区间太宽，什么也排除不了。这是有信息量的阴性结果。
6. **用"如果…就…"的规则替代"我们发现更好"。** v4 的可执行结论是：在采用更复杂的风险准则之前，先测它改变设计的比例。
7. **图注与正文分工。** 图注说明点、区间、单位、独立 n 和显示变换；正文只讲最关键的关系。
8. **每个数字能追到一个文件。** 见 `05_data_and_code/` 与 `validate_pack.py`。

## 3. 画图：诊断与改法

### v3 图的实际问题（本次逐幅核对）

- **图形摘要**：只有两个森林图和一句否定结论，没有视觉入口；网络、记录点、响应这条主线只用三个文字框表示；结论句是"没有证明"，读者带走的是"没用"。
- **Fig. 2**：两个散点占了一半版面，但回答的是描述性问题；主估计量被放到最下面；没有显示"两种准则选了同一组记录"这一最有解释力的事实。
- **Fig. 3**：包含一个 −11.7 的离群值，导致 b 面所有点挤在零附近，看不出 19/21 的分布；对数轴上同一坐标范围没有标出"预报高于实际"的方向。
- **Fig. 4**：横轴 −100 到 200，数值只能靠读轴估计；没有区分区间是否含零。

### v4 的改法

| 原则 | 具体动作 |
|---|---|
| 先给一个读者能带走的发现 | 图形摘要标题改成发现句，三栏对应三个问题：同一组记录？误差更低？预报更准？ |
| 把真实数据画成视觉入口 | 左侧用真实网络 J5000 的有符号权重画连接图，标出记录点、刺激点、读出点 |
| 最有解释力的事实用最直观的编码 | 82/120 与 26/40 用点阵：灰点＝同一组记录，彩点＝不同 |
| 主估计量放在读者找得到的位置 | 森林图配数值标签，标签、数值、误差线分三行，不重叠 |
| 离群值不删，但不让它支配版面 | Fig. 3b 按大小排序；−11.7 一条在轴上截断并直接标注数值 |
| 颜色有分工 | 群青＝单响应，朱红＝三响应，梅紫＝预报；同时用形状（圆、方、菱形）冗余编码；配色经色觉缺陷模拟检查，见 `03_figures/style/STYLE.md` |
| 实心／空心携带统计含义 | Fig. 4：实心＝区间不含零；空心＝含零 |
| 每幅图只回答一个问题 | Fig. 2 a/b/c＝决策是否不同／逐网络比值／主估计量 |

可复用部分：`03_figures/render_v4.py` 在文件开头对每个计数做断言（82/120、26/40、19/21、39/80、4/8），数字一旦偏离论文就停止出图。

### 作图检查清单（每幅图出稿前过一遍）

- [ ] 画布按最终物理尺寸设计（180 mm 或 190 mm），缩印后字号 ≥ 6.5 pt
- [ ] 独立样本单位写明（"40 independent networks"），嵌套重复不当作 n
- [ ] 零线与方向标注（"negative favours ensemble"）
- [ ] 区间类型和水平写明（97.5% 或 95%，配对网络聚类 bootstrap）
- [ ] 没有被删除的点；被截断的点有标注
- [ ] 文字不重叠；用缩小后的 PNG 肉眼检查，而不是只看矢量
- [ ] 颜色之外还有形状或填充区分
- [ ] 图中的每个数都能在 `source_data/` 里找到

## 4. 让结论"更有冲击力"：可以做什么，不能做什么

用户明确希望结论显得更乐观、更有影响。实验结果是：两个主比较和独立预报比较的区间都跨零。因此冲击力只能来自**如实写出的、有分量的内容**。

**可以做（v4 已做）**

- 把最强的真实发现放在最前：两种准则在 65–68% 的设计里选了同一组记录。
- 把阴性结果写成边界：三响应比较排除了大于约 3% 的下降。
- 把有利的探索性证据写出来：100 单元扩展 8 个设定中 4 个区间不含零，且都偏向 ensemble；没有一个在反方向不含零。同时写明 n=8、未校正、有一个设定符号反转。
- 给出可执行的结论和下一步：先测"准则改变设计的比例"；确认性研究固定小预算、排除端点、共享目标这几个设定。
- 用"证据账本"（论文 Table 2）让审稿人一眼看到每条主张的强度。

**不做**

- 不把跨零区间写成"趋势"或"接近显著"（预报比较 −0.456 [−1.159, 0.024] 的上界与零只差 0.024，但仍是未建立）。
- 不换主比较、不换指标、不换条件、不删网络，来得到一个更好看的结果。
- 不把 100 单元的探索结果提升为确认性结论，也不说"方法在大网络上有效"。
- 不暗示生物学或机器人层面的有效性。

这条边界不只是规范问题。本研究的价值本来就在"评价是否可信"，一旦主结果被修饰，三层审计这一最有可迁移价值的贡献也会一起失去可信度。
